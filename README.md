
# Phishing URL Detector

A machine learning-based cybersecurity project designed to identify potentially malicious phishing URLs using URL-based features.

## Overview

This project explores phishing detection using machine learning. It analyzes characteristics of URLs to distinguish potentially malicious links from legitimate websites.

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- Git & GitHub

## Features

- URL feature extraction
- Exploratory data analysis
- Machine learning model training
- URL classification and prediction
- Saved model for reuse

## Project Structure

- `feature_extraction.py` — Extracts URL-based features
- `train_model.py` — Trains the machine learning model
- `predict.py` — Runs predictions
- `explore_data.py` — Explores the dataset
- `explore_phishdataset.py` — Additional dataset analysis
- `domain_test.py` — Domain testing
- `phishing_model.pkl` — Saved trained model
- `data/` — Project datasets

## Future Improvements

- Develop an interactive Streamlit web application
- Improve feature engineering and model evaluation
- Add a user-friendly interface for URL classification

## Disclaimer

This project is intended for educational and cybersecurity research purposes. Predictions should not be treated as a guarantee that a website is safe or malicious.
